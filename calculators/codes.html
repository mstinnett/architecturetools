Codes & Standards

The reference sheet: which codes apply to a project and when, then every standard behind this suite's tools — editions, what each governs, and a link to the authoritative source. Editions shown are model-code baselines. Your jurisdiction's adopted edition and amendments govern, always.

What applies when
IBCInternational Building Code
Almost every building that isn't a house. Commercial, institutional, industrial, and multifamily (Group R-2 and up). The base document for occupancy, construction type, allowable height/area, fire protection, means of egress, and accessibility scoping.
IRCInternational Residential Code
One- and two-family dwellings and townhouses up to three stories with separate egress. A standalone code — its own structural, energy, plumbing, mechanical, and electrical chapters — so a house usually never touches the IBC.
IEBCInternational Existing Building Code
The moment the building already exists. Alterations, additions, repairs, and changes of occupancy route through its work-classification levels instead of full new-construction compliance.
IFCInternational Fire Code
Operations and the fire marshal's review. Companion to the IBC's chapters 9–10 — systems, hazardous materials, operational fire safety in occupied buildings.
IPC · IMC · IFGCplumbing · mechanical · fuel gas
The trade scopes on any non-IRC project. Fixture counts (IPC Table 403.1), ventilation and exhaust (IMC), gas piping and appliances (IFGC). Some states adopt UPC/UMC instead — check which family your jurisdiction runs.
IECC+ ASHRAE 90.1 alternative
Energy, on new work and most alterations. Envelope R/U by climate zone, lighting, systems. Commercial projects may comply via ASHRAE 90.1 instead — one path, declared, not both.
NEC / NFPA 70National Electrical Code
Electrical, everywhere. Adopted in some edition by every state; the I-codes defer to it.
NFPA 101Life Safety Code
Alongside the IBC for certain occupancies and reviewers. Healthcare (CMS requires it), many state fire marshals, federal facilities. Where both apply, egress satisfies both — the stricter provision governs in practice.
ADA 2010 Standardsfederal civil-rights law
An overlay, not an adopted code. Applies to public accommodations, commercial facilities, and state/local government work regardless of what the jurisdiction adopted — a building can pass plan review and still violate the ADA. Fair Housing design requirements play the same role for 4+ unit residential.
ICC A117.1accessible + usable buildings
The technical criteria behind IBC Chapter 11. The IBC scopes where and how many; A117.1 specifies how — turning spaces, clear widths, reach ranges. Largely harmonized with the ADA Standards, not identical.
ASCE 7minimum design loads
Whenever anything is sized structurally. Dead, live, snow, wind, seismic — referenced by IBC Chapter 16; the structural engineer's baseline.
Local zoningno national code
Before any of the above — every project. Use, FAR, setbacks, coverage, height, parking. Deliberately excluded from this suite's tools: each is jurisdiction-specific, so there is nothing general to compute from.
