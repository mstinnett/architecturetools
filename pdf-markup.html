What should I use to produce, mark up and check drawing sets?

Updated October 2026

PDF work on a project is seven jobs: producing sets, managing them while you work, assembling them to issue, marking them up, reviewing them live, taking quantities off them and checking them. Bluebeam’s Complete plan does the first six in one app and compares revisions as a check. Other tools each do part of that, often for less. Tools that check a set for errors are a newer, separate kind.

Produce
Publishing PDF sheets from Revit or AutoCAD.
Manage
The set while you work in it: links between sheets, and revised sheets swapped in.
Assemble
The set as it leaves your hands: combined into one file, labelled by sheet number, and stamped or sealed in one batch.
Mark up
Callouts and clouds, and a markups list you can sort, give a status and export.
Review live
Several people marking up one set at the same time.
Take off
Measuring to scale with points that snap to the drawing’s lines, counting, and exporting quantities.
Check
Verifying a set. A full mark is a tool built to find issues. A half mark is a way to compare revisions.

The marks describe each main app. Web, iPad and phone versions often do less. Prices are rounded. Check the vendor before you buy.

Not in the table: Preview, Okular and Xournal++ mark up a PDF for free, with no callouts, clouds or scaled measurement. Morpholio Trace measures to scale on an iPad but draws in pixels, for sketching over a plan rather than redlining it. Ncored, made by an architecture studio to open 50–200 MB CAD and BIM exports, does not list scaled measurement. None of the checking tools here was found to record which checks passed. Solibri, which checks IFC models rather than PDF sets, lists the rules that passed as well as the issues it finds.

Before you leave Bluebeam

Clouds, callouts and text are standard PDF markup, so other apps open them. Sets, custom markups-list columns and Studio Sessions work only in Bluebeam. PolyPDF imports Bluebeam tool chests (.btx). Test these on one of your own sets first:

  • Calibrate a sheet and measure a dimension you know.
  • Mark up a set in the new app and open it in Bluebeam, then the reverse. Check that clouds, callouts and colors are unchanged.
  • Rebuild the markups you use most, or import your tool chest if the app reads .btx files.
  • Review one set with a consultant. If they keep Bluebeam, decide who exports markups and who imports them.
