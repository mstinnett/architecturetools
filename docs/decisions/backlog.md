# Backlog — Work Source

The single source of work for the autonomous system. Seeded from the
"Current priorities" of `docs/PROJECT.md` and the build plan in
`docs/HANDOFF.md`; ad-hoc operator asks are added here too. `/work-next`
takes the topmost open item.

Mark items `- [ ]` (open) or `- [x]` (done). Keep the most important open
item on top. New findings are surfaced here or to the queue — never
silently appended elsewhere.

All build work happens on `dev`; finished tools promote to `main` one at a
time (see `docs/HANDOFF.md` §2).

## Open — product direction (operator, 2026-10-16)

Only the converter is published (`main`). The converter works as a product
because it shows the cost of rounding; each tool below needs its own "so
what" before it ships. Shipping state for the staged pages is in `state.md`.

- [ ] **Slope: fix the two-of-three inputs, then ship as the base and linker.** Today rise + run silently wins over a typed slope, and the worked example (run 9' + slope 8:12) puts the page in that state on the first keystroke. Rule: the two most recently edited fields govern; the third is the answer, drawn visibly different (no input box, result face, "calculated" tag), and typing into it makes it an input. Put the pattern in shared code — Roof and Ramp reuse it. Move the slope math (parse %, x:12, 1:n, °, and civil **H:V** — "3:1" on a grading plan is 3 across, 1 up; today it reads as 71°) into `calculators/lib/slope.js`. Under the answer, hand off to **Roof / Ramp / Drain** with the values in the URL, suggesting one from the regime (≤ ¼"/ft → Drain, 1:20–1:12 → Ramp, ≥ 2:12 → Roof). Common slopes grouped: accessibility, roofing minimums, earthwork (OSHA A/B/C; angles of repose as ranges), landscape (3:1 mowable, 2:1 planted), stairs/ladders.
- [ ] **Drain page (new).** Min slope for drainage, both ways: length → height used (drop + pipe OD + hanger/insulation allowance) and available height (plenum, joist, slab recess) → max length at min slope. Start from *what drains*, not a number: DWV pipe by size (¼"/ft ≤ 2½", ⅛"/ft 3–6", 1/16"/ft ≥ 8"), condensate, shower floor (¼–½"/ft; accessible 1:48 cross slope), low-slope roof, gutters, grade at foundation (6" in 10'), paving. Located and cited, not ruled — **verify every value against current IPC/UPC/IMC/IBC/IRC before shipping** (seeded from memory). Rounding is the so what: drop is built to ⅛"/¼", and rounding the wrong way lands under the minimum.
- [ ] **Ramp page.** Rebuild `dev`'s `calculators/ramp.html` on `lib/slope.js`: run length, landings/stops, 30" rise per run, total floor area taken.
- [ ] **Roof page (new), on the slope substrate.** Lead: height at any point read off a plan — plate + (plan distance to nearest eave × pitch); ridge from half-span; 5'/7' headroom lines; eave–ridge midpoint for zoning height. Then roof area = plan area × pitch factor → squares. Then low slope (shares Drain's math): drain spacing → taper height at high points, crickets, curb/parapet height. Hips: not needed for heights; show only for unequal pitches (hip not at 45° in plan) and as an expandable framing detail.
- [ ] **Tile splits in two.** *Tile Layout* — straight-line and corner grid (roughly the staged `tile.html`), ships first. A separate CAD-like surface product grows from `dev`'s Pattern The Surface / drag surface / CAD exact-kernel work.
- [ ] **PDF markup page → listicle.** Strip the review voice (verdicts like "the strongest", "the best pen experience", the Bluebeam-is-standard lede): a numbered list of tools with the same facts per entry (maker, kind, platforms, measurement, team review, price, a one-line "what it is"). Adequate Design Review is the operator's own product — keep it in the list on the same terms, with a disclosure line.
- [ ] **BIM → a history and a space to watch.** One page: a timeline of product introductions (AutoCAD, ArchiCAD, Vectorworks/MiniCAD, Revit, SketchUp, Rhino/Grasshopper, IFC, the visualizers, through Forma and the browser tools) — **every year sourced before publishing**; then a dated "space to watch" of current developments from AEC Magazine and others, each item linked to its source. Folds in `bim-emerging.html`; decide whether `bim-platforms.html`'s filterable list survives beside it.
